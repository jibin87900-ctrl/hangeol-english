# 2026-11-03 리서치: Drops 5분 단어 세션 · LingQ Mini Stories

관점: **짧고 가벼운 단어 학습 흐름**(시간 제한, 이미 아는 단어 건너뛰기)과 **같은 이야기를 여러 번 반복해서 듣고 읽게 하는 설계**. 최근 조사(10/27~11/02)에서 다루지 않은 두 앱을 골랐다.

참고: 이번 실행 환경에서는 blog.thelinguist.com, goodux.appcues.com 페이지를 직접 열 수 없었다(네트워크 제한). 아래 내용은 **검색 결과에 나온 내용만** 근거로 썼고, 대부분 제3자 리뷰라 공식 자료로 다시 확인할 필요가 있다.

## 1. Drops — 5분 그림 단어 세션
- 5분짜리 게임 같은 세션과 그림으로 단어를 가르친다. 개발사는 그림으로 뜻을 외국어 단어에 바로 연결한다고 설명한다. 같은 주제 안에서 단어를 글·그림·소리로 여러 번 다시 만난다.
  - https://www.fluentu.com/blog/reviews/drops-language-app/
  - https://www.fluentu.com/blog/drops-language-app-review/
- 학습 시간을 제한하는 이유로 "오히려 더 계속하고 싶게 만든다"는 개발사 설명, "강도보다 꾸준함을 강제한다"는 리뷰가 있다.
  - https://cellphoneplans.androidauthority.com/CellPhones/Guides/drops-the-language-learning-app
- **이미 아는 단어는 위로 밀어서 "알아요" 처리하고 레슨에서 뺄 수 있고**, 아래로 밀면 배우겠다는 뜻이 된다. 아는 단어를 건너뛰어 레슨이 빨리 끝난다는 리뷰가 있다.
  - https://www.alllanguageresources.com/language-drops-app/
  - https://blogs.reed.edu/langlabbies/2019/11/07/drops-app-for-learning-vocabulary/
- 단어만 다루고 문법·문장 구조는 다루지 않아 다른 과정과 함께 쓰라는 리뷰가 많다. 무료판은 시간 제한과 광고가 있다.
  - https://www.fluentu.com/blog/reviews/drops-language-app/
- 검색 결과로는 Drops의 간격 반복 일정이 정확히 어떻게 돌아가는지는 확인하지 못했다.

**시사점**: 우리 사용자는 쉬운 단어를 조금 안다. 기본 단원 레슨에서 이미 아는 단어를 "알아요"로 빼는 기능은 지루함을 줄인다. 반대로 "아는 단어만 있다"는 느낌을 막으려면 뺀 단어도 단어장에서 보이게 해야 한다.

## 2. LingQ — Mini Stories
- 60개 짧은 이야기로 된 초급 시리즈로, 점점 어려워지고 원어민 음성이 붙어 있다.
  - https://storylearning.com/lingq-review
  - https://www.alllanguageresources.com/lingq-review/
- 각 이야기는 **본문 → 다른 시점·인칭·시제로 다시 말하기 → 내용 질문** 순서로 같은 어휘를 여러 번 반복한다. 영어 코스 목록에서도 "1a - Mike Is a Cook, Part 1 / 1b Part 2 / 1c Questions"처럼 이야기 뒤에 질문 레슨이 따로 있다.
  - https://blog.thelinguist.com/what-are-lingq-mini-stories-and-why-they-work/ (검색 결과 요약)
  - https://blog.thelinguist.com/learning-new-languages-mini-stories (검색 결과 요약)
  - https://www.lingq.com/en/learn-english-online/courses/2377872/
- 단어는 New → LingQ(배우는 중) → Known으로 상태를 바꾸고, Known 단어는 복습(SRS)에 안 나온다고 공식 도움말이 설명한다.
  - https://lingq-support.groovehq.com/help/understanding-lingq-statistics
  - https://lingq-support.groovehq.com/help/how-do-i-increase-my-known-words
- 한 리뷰는 이야기가 초반 동기를 유지할 만큼 재미있지는 않다고 비판했고, 초급 코스가 끝나면 수준에 맞는 자료를 혼자 찾아야 한다고 했다.
  - https://storylearning.com/lingq-review

**시사점**: 우리 매일 단원 대화(A·B 역할)를 **'나'의 시점으로 다시 말한 짧은 요약 한 줄**(예: "My drink was missing, so the driver brought it later.")로 보여 주면 같은 단어를 다른 문장으로 한 번 더 만난다. 콘텐츠만 늘리면 되는 일이라 위험이 낮다.
